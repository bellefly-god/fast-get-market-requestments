# Smart Fit Plan

## Local Setup

### Requirements
- Node.js 20+ (tested with Node.js 24.13.0)
- npm 10+

### Install
```bash
npm install
```

### Start Dev Server
```bash
npm run dev
```

Default URL:
- `http://localhost:5173/`

### Build
```bash
npm run build
```

### Test
```bash
npm test
```
